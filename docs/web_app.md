# Web版（ブラウザだけで計算する）

Pythonのインストールなしで、ブラウザだけで敷地条件を入力して最大ボリューム
を計算・3D表示できる版です。**通信は一切しません**（外部ライブラリもCDNも
使っていません）。

## 使い方

### 単一ファイル版（配布・持ち歩き向け）

```bash
python3 tools/build_web.py
```

`dist/jwcad-volume-web.html` が1つできます（約78KB）。これをダブルクリック
すればブラウザで開きます。USBメモリで持ち歩いても、メールで送っても動きます。

### 分割版（開発・GitHub Pages向け）

`web/index.html` をそのまま開くか、`web/` をWebサーバに置いてください。

```
web/
  index.html    画面
  engine.js     斜線制限・天空率・日影の計算
  envelope.js   最大ボリューム探索
  viewer.js     3D描画（Python版の出力と共通）
  app.js        画面とエンジンの接続
```

## 入力できること

- **敷地形状**: 長方形（間口×奥行）か、頂点座標の直接入力
- **各辺の境界種別**: 道路 / 隣地 / 北側 / 規制なし
- **前面道路の幅員・境界からの後退**
- **用途地域・容積率・建蔽率・絶対高さ制限・階高**
- **日影規制**: 緯度、第1種／第2種測定線の距離と時間数
- **計算精度**: 速い（数秒）／標準／精密

## Python版との連携

| やりたいこと | 方法 |
|---|---|
| Web版で検討 → DXFやJWWに出す | 「設定YAMLを保存」→ Python版に渡す |
| Python版の設定をWeb版で開く | 「設定YAMLを読み込み」 |
| 結果を3D HTMLで配る | 「3D HTMLを保存」（単一ファイル版のみ） |

保存したYAMLはそのまま使えます。

```bash
jwcad-volume site.yaml --dxf-out 結果.dxf
```

3D描画のコード（`web/viewer.js`）はPython版の出力にも埋め込まれるので、
どちらで作った3D HTMLも見え方は同じです。

### 「3D HTMLを保存」が使えるのは単一ファイル版だけ

分割版では、JavaScript側から `viewer.js` の中身を文字列として読めない
ため（`file://` では取得が禁止されている）この機能だけ無効になります。
`tools/build_web.py` で作った単一ファイル版を使うか、設定YAMLを保存して
Python版で出力してください。

## Python版と同じ答えが出るのか

出ます。`tests/test_js_parity.py` が、実際にNode.jsでJS版を走らせて
Python版の結果と突き合わせています。太陽位置・斜線制限の逆算・適合建築物・
天空率・日影時間・最終的なボリューム・サマリー文字列まで、同じ入力なら
同じ結果になることを自動テストで担保しています。

実測例（30m角の敷地、天空率あり）:

| | Python版 | Web版 |
|---|---|---|
| 体積 | 30560.6 m3 | 30561 m3 |
| 最高高さ | 72.86 m | 72.9 m |
| タワー | 2段 +40.2m | 2段 +40.2m |

### 実装が違う部分

**日影計算**だけ内部のやり方が違います。Python版はshapelyの多角形和集合
で影の領域を作ってから測定点を判定しますが、Web版は和集合を作らずに
判定します。点Pが「平面形状F」と「影のずれベクトルd」のミンコフスキー和
F⊕[0,d] に入る条件は

```
線分 [P-d, P] が F と交わること
```

と数学的に同値なので、線分交差判定だけで厳密に同じ答えが出ます。多角形
ブーリアン演算のライブラリをブラウザに持ち込まずに済むのが利点です。

**敷地が凸でない場合のセットバック**（内側への縮小）は、Python版が使う
shapelyの `buffer(-d)` と厳密には一致しないことがあります。長方形など
通常の凸な敷地なら一致します。凹んだ形の敷地で精密な数値が必要な場合は
Python版を使ってください。

## 制限

- 計算はブラウザのメインスレッドで動きます。「精密」設定と大きな敷地の
  組み合わせでは、計算中に画面が固まったように見えることがあります。
- DXF出力・JWW外部変形への出力はPython版のみです。
- 設計初期段階の検討用です。確認申請には使えません
  （`disclaimer.md` を参照）。
