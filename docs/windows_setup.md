# Windows導入手順

使い方は2通りあります。目的に応じて選んでください。

| | A. コマンドで実行 → DXFをJWWで開く | B. JWWの外部変形として使う |
|---|---|---|
| 手軽さ | ◎ すぐ試せる | △ exeビルドが必要 |
| 確実性 | ◎ **実機のJWWで表示を確認済み** | △ 外部変形の書式は実機未検証 |
| 操作感 | 敷地条件をYAMLに書く | JWW上で敷地を選んで実行 |
| 手順 | 下の「A」 | 下の「B」 |

まずAで計算内容を確認し、納得できたらBに進むのがおすすめです。

---

## 事前準備: Pythonの導入

方法Aと、方法Bのexeビルドには Python 3.9以上 が必要です
（ビルド後のexeを使う人のPCにはPythonは不要です）。

1. <https://www.python.org/downloads/> からWindows版をダウンロード
2. インストーラの最初の画面で **「Add python.exe to PATH」に必ずチェック**
3. コマンドプロンプトを開いて確認:

```
python --version
```

`Python 3.x.x` と表示されればOKです。

## コードの取得

gitがある場合:

```
git clone https://github.com/naoki-ohashi/sim.git
cd sim
git checkout claude/jwcad-building-volume-calc-a56sbi
```

gitが無い場合は、GitHubのブランチページで
**Code ▾ → Download ZIP** を選び、展開したフォルダへ
コマンドプロンプトで `cd` してください。

---

## A. コマンドで実行してDXFをJWWで開く

```
pip install -e .
jwcad-volume examples\sample_site.yaml
```

`jwcad-volume` が見つからないと言われたら、代わりに:

```
python -m jwcad_volume.cli examples\sample_site.yaml
```

計算結果が画面に出て `envelope.dxf` が作られます。
`examples\sample_site.yaml` をコピーして敷地の条件に書き換え、

```
jwcad-volume 自分の敷地.yaml --dxf-out 結果.dxf
```

生成された `.dxf` をJWWのDXF読込で開けば、平面・断面・サマリーが
図面に入ります（レイヤ構成は `jww_integration.md`）。

## B. JWWの外部変形として使う

### B-1. exeをビルドする

リポジトリのフォルダで:

```
build_windows.bat
```

`dist\jww\` に必要なファイル一式ができます。このフォルダごと
好きな場所（例: `C:\jwcad-volume\`）に置いてください。

> このビルドスクリプトはLinux環境で開発したため、Windows実機での
> 検証ができていません。エラーが出たらメッセージを添えて報告してください。
> よくある原因は shapely のバイナリ依存で、その場合は
> `--collect-all shapely` の追加指定で解決することが多いです
> （スクリプトには既に入れてあります）。

### B-2. 敷地条件を設定する

`dist\jww\gaihen_params.yaml` を開き、用途地域・容積率・建蔽率・
道路幅員・日影規制の時間数などを敷地に合わせて書き換えます。
**敷地の形だけは図面から読み取る**ので、YAMLには書きません。

### B-3. JWWで敷地を描く

敷地の外形線を、辺ごとに**線色を変えて**描きます。

| 線色 | 意味 |
|---|---|
| 線色1 | 道路境界線 |
| 線色2 | 隣地境界線 |
| 線色3 | 北側境界線（真北側の辺に使う） |
| その他 | 規制なしとして扱う |

この対応は `gaihen_params.yaml` の `boundary_colors` で変更できます。
幅員の違う道路が2本ある場合は、道路ごとに別の線色を割り当てて
`road_width_by_color` で幅員を指定してください。

外形線は**きちんと閉じた形**にしてください。角が離れていたり、
線が余分に飛び出していると計算できません（エラーで具体的な座標を出します）。

### B-4. 実行する

1. 敷地の外形線を範囲選択
2. [その他] - [外部変形]
3. `最大ボリューム計算.bat` を選ぶ

結果（各段の平面輪郭とサマリー文字）が、`result_layer` で指定した
レイヤに作図されます。

### B-5. うまく動かないとき

まず **`診断_データ確認.bat`** を実行してください（図面は変更しません）。
`dist\jww\` に次の2つができます。

- `JWC_SAMPLE.TXT` … JWWが実際に渡してきた生データ
- `診断結果.txt` … 本ツールがそれをどう読んだかの報告

`診断結果.txt` の見どころ:

- **「線分として読めた行」が0** → JWWのデータ書式が本ツールの想定と
  違います。`JWC_SAMPLE.TXT` を添えて報告してください。
- **「座標範囲」が敷地の実寸と桁違い** → `units_per_meter` の設定が
  違います（JWWの実寸mm作図なら1000、m単位作図なら1）。
- **「閉じた敷地形状にできませんでした」** → 外形線が閉じていないか、
  余分な線が選択に含まれています。メッセージの座標を確認してください。
- **「解釈できなかった行」に線分らしきものがある** → 書式の想定違いです。

### 制御行の調整

`最大ボリューム計算.bat` の先頭3行:

```
REM #jww
REM #cd
REM #e
```

これはJWWへの制御指示です。`REM #jww` が外部変形であることの宣言、
`REM #e` が制御ブロックの終わりを表す、という理解で書いていますが、
**実機JWWで検証できていません**。JWWがバッチを認識しない・データを
渡してこない場合は、お使いのJWWのヘルプ「外部変形」の項や、既存の
外部変形プログラムのバッチ冒頭を参考に、この3行を差し替えてください。
計算本体（exe）はこの制御行に依存しないので、ここだけの調整で済みます。
