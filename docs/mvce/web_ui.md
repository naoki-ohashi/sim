# MVE Web版UI（ブラウザだけで使う）

Pythonのインストールもコマンド入力も不要で、**ブラウザだけ**で敷地条件を
入力して最大ボリュームを計算できます。通信は一切しません。

## 使い方

```bash
python3 tools/build_mvce_web.py
```

`dist/MVCE.html` が1つできます（約250KB。大半はDXF書き出し用の
Shift_JIS変換テーブルです）。これを**ダブルクリック**
するだけです。USBメモリで持ち歩いても、メールで送っても動きます。

開発時は `web/mvce/index.html` をそのまま開いても使えます。

## 画面

左が入力フォーム、右が図です。

### 入力（7つのセクション）

1. **敷地の形** — 長方形（間口×奥行）か、頂点座標の入力
2. **真北** — 図面の上から反時計回りの角度。北側斜線と日影がこの向きに追従します
3. **各辺の境界と壁面後退** — 辺ごとに 道路/隣地/対象外、道路幅員、壁面後退距離、
   外側の公園・水面・線路敷、高低差
4. **用途地域など** — 用途地域、容積率、建蔽率、絶対高さ制限、階高
5. **日影規制** — 測定面（1.5/4/6.5m）、5m超10m以内と10m超の規制時間、緯度、北海道、
   等時間日影図の時間（カンマ区切り、空欄なら計算しない）とグリッド間隔
6. **天空率（法56条7項）** — 斜線制限の代わりに天空率で検討するかのON/OFF、
   測定点の間隔、方位の分割数
7. **メッシュ** — X方向・Y方向の幅

入力を変えると平面図がその場で更新されるので、辺の番号と実際の位置の
対応が目で確認できます。容積率が前面道路幅員で下がる場合（法52条2項）は、
その場で注意書きが出ます。

### 図（2つのタブ）

- **平面図** — 敷地、前面道路（幅員ぶんの帯）、壁面後退線、メッシュの各マスと
  その階数、辺の番号、真北記号。マウスホイールでカーソル位置を中心に
  拡大縮小できます（敷地の形を変えると自動フィットに戻ります）
- **3D** — マウスで回せます。最大ボリューム（オレンジ）と斜線制限の
  エンベロープ（青の半透明）、前面道路（幅員ぶんの帯＋反対側境界線）、
  日影5m/10m測定線、等時間日影図を重ねて表示（それぞれ表示のON/OFFを
  切り替え可能）

## 敷地の読み込み・書き出し

「敷地を読み込み」ボタンは拡張子でファイルの種類を判定します。

- **YAML**（`.yaml`/`.yml`） — Python版の設定ファイルとそのまま相互に渡せます
- **JSON**（`.json`） — HBU-ANALYZER等が出力する `{ "points": [...], "edges": [...] }`
  形式（`mvce/io/site_json.py` と同じ検証ロジック）
- **CSV**（`.csv`） — 1行1頂点、`x`/`y`列は必須、`kind`/`road_width_m`/
  `wall_setback_m`/`relaxation_kind`/`relaxation_width_m`/`ground_level_diff_m`/`label`列は任意
  （`mvce/io/site_csv.py` と同じ検証ロジック）

「設定YAMLを保存」で書き出したファイルは、Python版にそのまま渡せます。

```bash
mvce 敷地.yaml --dxf-out 図面.dxf
```

「DXF図面を保存」で、JW-CADが読める形式（R12・mm・Shift_JIS）のDXFを
ブラウザから直接ダウンロードできます。レイヤ構成はPython版の`mve`コマンド
（`mvce/io/drawing.py`）と同じです。ただしPython版が結合した1本の輪郭線で
描く「各階の平面輪郭」は、Web版ではメッシュのマス単位のまま出力します
（見た目は同じですが、CAD上で線分の分割が細かくなります）。

## Python版と同じ答えが出るのか

出ます。実際にNode.jsでJS版を走らせてPython版と突き合わせる自動テストが
あります。

- `tests/mvce/test_js_parity.py` — 太陽位置・法52条2項・斜線制限（令132条の
  複数道路・各種緩和・高低差・真北の回転を含む）・日影のみなし境界線・
  天空率（測定点・適合建築物・Ps/Pr・**日影との同時最適化**）・メッシュ・
  **各マスの階数**・最終的な延床面積・サマリー文字列・**等時間日影図**
  （グリッド日影時間・マーチングスクエア法の線分集合）
- `tests/mvce/test_js_site_import_parity.py` — 敷地JSON/CSV読み込みの検証
  （正常系・異常系とも）
- `tests/mvce/test_js_dxf_compat.py` — DXF書き出し（JW-CADが読める形式か、
  Shift_JIS変換テーブルがPythonのcp932コーデックと一致しているか）

### 実装が違う部分

Python版は多角形の交差に shapely を使いますが、ブラウザ版はライブラリを
持ち込まずに済むよう**半平面クリップ（Sutherland–Hodgman）**で代用して
います。敷地が凸（長方形など通常の敷地）なら結果は一致します。凹んだ形の
敷地では、メッシュのマスが外郭線をはみ出す量の判定がわずかに変わることが
あります。厳密な数値が必要な場合はPython版を使ってください。

## 制限

- 計算はブラウザのメインスレッドで動きます。メッシュを細かくすると
  （1m など）計算中に画面が固まったように見えることがあります。等時間
  日影図はグリッド間隔を狭くするほど時間がかかります。
- 敷地図のDXF読み込み（DXFから頂点・辺の種別を推測して取り込む機能）は
  Python版のみです。Web版はYAML/JSON/CSVの読み込みとDXFの書き出しに対応
  しています。
- 逆日影（屋根越し・棟状パターン）はPython版のみです。天空率を使う場合、
  ブラウザ版は常に自由形（voxel）で検討します。
- 設計初期段階の検討用です。確認申請には使えません（`disclaimer.md`）。
