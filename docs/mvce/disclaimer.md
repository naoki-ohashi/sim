# MVE の免責事項・位置づけ

MVE（Maximum Volume Engine）は、建築基準法の斜線制限・日影規制・容積率を
ふまえて敷地に建てられる最大容積を試算する、**設計初期段階の検討ツール**
です。

## 確認申請には使えません

- **天空率**の**算定位置**は令135条の9・10・11 に合わせました（2026-08-30）。
  基準線・間隔・想定半球の中心の高さは条文どおりです。
  ただし**天空図の投影方法はまだ近似**で、正射影（ρ = cos仰角）による方位の
  等分サンプリングです。また令135条の5 の Ab は「建築物**及びその敷地の
  地盤**」ですが、地盤の投影は見ていません（平坦地では寄与しません）。
  Ps と Pr を同じ方法で比較しているので相対比較の一貫性はありますが、
  **天空率の絶対値を認定ソフトの数値と突き合わせる用途には使えません**。
  実際の申請には認定を受けたソフトウェアが必要です。
- **適合建築物**（令135条の6・7・8）は、斜線制限ぎりぎりの形を階段状に
  近似したものです。階段室等・棟飾等の除外、勾配が異なる地域等ごと・
  令132条／令134条2項の区域ごと・高低差区分区域ごとの分割には対応して
  いません。
- **日影図**も同様で、測定点は等間隔サンプリングによる近似です。等時間
  日影線（2時間線・3時間線などの等高線）はオプション（`isochrone_hours`）
  で作図できますが、これもグリッドサンプリングによる近似で、告示が定める
  厳密な方法には準拠していません。またDXFとPython生成の3D HTMLのみの
  対応で、ブラウザ版（JS）インタラクティブUIでは作図できません。
- 平均地盤面（令2条2項）は `ground.py` で算定できますが、斜線・絶対高さ・
  日影の測定面をそこから測るところまで繋いでいません。いまも Z=0 を
  地盤面として高さを判定しているので、傾斜地では実際と乖離します。

## 数値は必ず確認してください

以下は都市計画と条例で決まるもので、MVEに既定値を置いていない、または
既定値が説明用の一例に過ぎないものです。

- **日影規制の測定面**（1.5m / 4m / 6.5m）と**規制時間**（別表第四）
- **容積率・建蔽率**
- **絶対高さ制限**の有無と値
- 公園・水面・線路敷の緩和対象になるかの判断
  （隣地斜線では都市公園法の都市公園を除く運用が一般的です）

`ShadowRegulationSpec` は測定面と規制時間を必須の入力にしてあり、既定値で
黙って計算が進むことがないようにしています。

## 未対応の項目

`legal_basis.md` の「未実装・簡略化している点」に一覧があります。主なもの:

- 令135条の12第2項（日影の高低差緩和）
- 法52条9項（特定道路による容積率の緩和）
- 平均地盤面の算定
- 3本以上の道路が複雑に絡む場合の令132条の運用差

## アルゴリズムの限界

最大容積の探索は**貪欲法で、大域最適解ではありません**。結果はメッシュの
粗さにも依存します。「この条件ならこのくらいは入る」という下限の目安として
使い、最終的な形状は設計者が判断してください（`methodology.md`）。

## 使い方の前提

MVEの計算結果は、**建築士等の専門家による確認・検証を経てから**実務に
用いてください。重要な案件では特定行政庁への事前相談を行ってください。
