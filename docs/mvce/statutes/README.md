# 条文アーカイブ

MVCE が実装している条文の**原文**を、出典と取得日を添えて置いておく場所です。

## なぜリポジトリに置くのか

基本設計書 第0章は「条文番号・数値は、実装前に必ず e-Gov 法令検索の原文と
照合すること。基本設計書の数値を一次情報として扱ってはならない」と定めて
います。

一方で、実装作業をする環境から e-Gov に到達できるとは限りません
（実際、Claude Code のリモート実行環境は egress ポリシーで
`laws.e-gov.go.jp` に出られません）。原文をリポジトリに置いておけば、

- オフラインでも照合台帳（`../legal_basis.md`）を埋められる
- **どの版で実装したか**が git に残る
- 条文が改正されたとき、差分が git diff で見える

という3つが同時に手に入ります。改正は必ず起きるので、3つめが本命です。

## 置き方の規約

- 1つの法令につき1ファイル。ファイル名は法令名そのまま
- ファイルの先頭に**必ず**次のメタデータを置く

  | 項目 | 内容 |
  |---|---|
  | 法令番号 | 例: 昭和二十五年政令第三百三十八号 |
  | 施行日 | その版の施行日 |
  | 出典 | e-Gov 法令検索の URL |
  | 取得日 | 原文を取得した日 |
  | 取得方法 | 誰がどうやって取ってきたか |

- 条文は**一字一句そのまま**。要約・現代語訳・体裁の整形をしない。
  漢数字を算用数字に直すのも禁止（「三メートル」を「3メートル」に
  しない）。実装側で読み替えるのは構いませんが、それは実装の仕事で
  あって、このアーカイブの仕事ではありません
- 全文でなくてよい。必要な条だけを、抜粋であることを明記して置く

## 「取得方法」を書く理由

原文を誰がどう持ってきたかで、信頼の度合いが変わります。

- e-Gov から機械的に取得したもの — 転記ミスの余地なし
- 人が e-Gov から転記して貼り付けたもの — 転記ミスの余地あり。
  重要な数値を実装に落とすときは、もう一度原文にあたるのが安全

どちらも使いますが、**どちらなのかが分からない状態にはしない**という
ことです。原則F（出典必須）と同じ趣旨です。
