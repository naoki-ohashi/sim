# 方式の資料（法令ではありません）

天空率の適合建築物・算定位置の作り方には、法・施行令だけでは決まらない
部分があります。そこを埋めているのが**方式**（東京都方式・JCBA方式・
新JCBA方式・JCBO方式）です。

このフォルダは方式の資料を置く場所です。**`../statutes/` とは分けてあります。**
根拠の強さが違うものを同じ棚に置くと、あとで判断を誤るためです。

| | 根拠 | 拘束力 |
|---|---|---|
| `../statutes/` | 法・施行令 | 法令そのもの |
| `methods/`（ここ） | 行政会議の取扱い・ベンダーの解説 | 運用。行政庁により異なる |

実装では、方式に由来する選択は `ComplianceProfile`（`mvce/profiles/`）に
入れて、`source` にこのフォルダの資料を指します。条文由来の値とは
別に持ちます。
