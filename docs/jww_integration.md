# JW-CAD/JWWへの取り込み方法

## 推奨: DXF読み込み（検証済み・確実）

`jwcad-volume` はDXFファイルを出力します（`output.dxf_path`）。JWWの
[ファイル]-[開く] または [DXF読込] 相当の機能でこのDXFを読み込めば、
敷地境界線・各段のボリューム輪郭（平面）・断面・サマリーテキストが
図面に取り込まれます。レイヤー構成は以下の通りです。

| レイヤー | 内容 |
|---|---|
| `SITE` | 敷地境界線 |
| `ENVELOPE-PLAN` | 各高さ段の平面輪郭（段ごとに色分け） |
| `ENVELOPE-PLAN-TEXT` | 各段の高さ範囲ラベル |
| `SECTION-GL` | 断面図のグランドライン |
| `ENVELOPE-SECTION` | 断面図（切断位置は `output.section_axis` / `section_position` で指定） |
| `SUMMARY` | 敷地面積・容積対象床面積・天空率適合状況・日影規制適合状況などのテキスト |

これはJWWの標準機能のみに依存するため、外部変形プログラムとして
登録しなくても、単に `jwcad-volume` をコマンドラインで実行して
DXFを生成し、JWWで開くだけで使えます。

## 外部変形プログラムとしての登録（Windows / JWW本体が必要）

JWWの [その他]-[外部変形] メニューから直接このツールを呼び出したい場合は、
次の手順が必要です。

1. `pyproject.toml` の `[project.scripts]` にある `jwcad-volume` コマンドを
   PyInstaller等でWindows用の単体exeにビルドします
   （例: `pyinstaller --onefile -n jwcad_volume jwcad_volume/cli.py`。
   Windows環境でのビルドが必要です。本リポジトリの開発・テストはLinux
   サンドボックス上で行っており、実機Windows/JWWでのビルド・動作確認は
   行っていません）。
2. JWWの外部変形リストにこのexeを登録します（登録方法はJWWのバージョンに
   よって異なります。JWWのヘルプ「外部変形」の項目を参照してください）。

## 実験的機能: JWWネイティブ外部変形データ形式（未検証）

`output/gaihen_text.py` は、JWWの外部変形が本来やり取りする独自テキスト
形式（選択図形をテキストファイルに書き出し、外部プログラムがそれを
上書きして返す仕組み）に**近い形**でデータを書き出す実験的な実装です。

**重要:** このモジュールが出力する形式は、実際のJWWインストールに対して
検証できていません。フィールドの区切り方・レイヤー番号の割り当て・
文字コード・改行コードなど、JWWの実バージョンと食い違っている可能性が
高いです。実際にJWWと連携させる場合は、まずJWW側で何もしない単純な
外部変形サンプル（あるいは既存の外部変形プログラム）が書き出す一時
ファイルを確認し、そのフォーマットに合わせて `gaihen_text.py` の
`_format_line_entity` を調整してください。

現時点では、DXF読み込みの方が確実に動作します。ネイティブ外部変形形式は
「将来的にJWWとの直接連携を実装する際の出発点」として用意しています。
