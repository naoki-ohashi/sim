# SiteInfo 入力要件ノート（大橋の指示）

> SiteInfo の入力項目と入力方法について、オーナー（大橋）から指示された要件を
> 記録したものです。SiteInfo 項目定義書、DB 設計、入力・確認画面設計、Codex
> 向け実装指示書は、すべてこのノートを満たすように作ります。
> 全体の考え方は [`vision.md`](vision.md) を参照。

## 1. 重要事項説明書の「法令上の制限」を必須入力項目にする

宅地建物取引業法 35 条の重要事項説明書に記載する **法令に基づく制限** を、
SiteInfo の必須入力項目とします。取引の場面で必ず確認される項目なので、
SiteInfo の出発点として欠かせません。

項目定義書では、少なくとも次の区分を網羅します（条文・最新の様式で要確認）。

### 都市計画法
- 区域区分（市街化区域／市街化調整区域／非線引き／都市計画区域外）
- 用途地域、特別用途地区、高度地区、高度利用地区
- 防火地域・準防火地域
- 地区計画、市街地再開発事業、土地区画整理事業、都市計画道路等の都市施設
- 開発許可の要否、風致地区、景観地区

### 建築基準法
- 建蔽率・容積率（指定値、角地・防火等の加算、前面道路幅員による制限）
- 高さ制限（絶対高さ、道路斜線、隣地斜線、北側斜線、日影規制）
- 接道（道路種別 42 条 1 項・2 項等、幅員、セットバック、私道負担）
- 建築協定、壁面線、外壁後退、敷地面積の最低限度
- 条例による制限（緑化、駐車場附置、ワンルーム等）

### その他の法令（重要事項説明書で列挙されるもの）
- 国土利用計画法、農地法、宅地造成及び特定盛土等規制法、土砂災害防止法、
  津波防災地域づくり法、急傾斜地法、河川法、港湾法、海岸法
- 景観法、文化財保護法（埋蔵文化財包蔵地）、自然公園法、都市緑地法、
  生産緑地法、土壌汚染対策法、大規模小売店舗立地法
- 水害ハザードマップ上の位置（水防法）、造成宅地防災区域、
  土砂災害警戒区域・特別警戒区域、津波災害警戒区域

### 供給施設・その他
- 上下水道・ガス・電気の整備状況、私道負担、石綿・耐震診断の記録の有無

## 2. 日影規制の条件を入力できるようにする

日影規制は、用途地域から自動で決まるのではなく、**自治体が条例で指定した
組み合わせ**を入力できるようにします。

| 入力項目 | 内容 |
|---|---|
| 測定面の高さ | 1.5m / 4.0m / 6.5m |
| 5m 超 10m 以内の規制時間 | 例: 3 時間、4 時間、5 時間 |
| 10m 超の規制時間 | 例: 2 時間、2.5 時間、3 時間 |
| 対象建築物の基準 | 軒高 7m 超または 3 階以上／高さ 10m 超 |
| 北海道区分 | 真太陽時 9〜15 時の適用 |

- 別表第四の代表的な組み合わせ「3 時間／2 時間」「4 時間／2.5 時間」
  「5 時間／3 時間」をプルダウンで選べるようにしつつ、条例の値を自由入力
  できるようにする。
- MVE の `shadow` 設定（`measurement_height_m`、`line_5m_max_hours`、
  `line_10m_max_hours`）は、この入力からそのまま生成できる形にする。

## 3. 行政 GIS・GeoJSON からの自動入力（補助として）

敷地の住所、またはポリゴン等で位置が特定された場合、行政が公開している
GIS・GeoJSON 等から得られる情報を、入力欄へ **可能な限り自動で** 入れます。

ただし、次の前提を守ります。

- 自治体によって公開形式や項目の表現がまちまちなので、自動入力は
  **補助**と位置づける。
- 自動入力された値は、**必ず入力するユーザーが最終確認**する。最終確認を
  経ていない値は未確定として扱う。
- 土地の情報は、一つ一つデータベースを作っていく出発点として極めて重要な
  情報なので、手入力での最終確認を前提に運用する。

### 設計への反映

各項目は「値」だけでなく、次の付随情報を持つ設計にします。

| 属性 | 内容 |
|---|---|
| 値 | 項目の入力値 |
| 取得元 | 自動（GIS 名・データセット名・取得日）／手入力 |
| 確認状態 | 未確認／確認済み |
| 確認者・確認日時 | 最終確認したユーザーと日時 |
| 備考 | 自治体の提示方法の違いや判断理由のメモ |

入力・確認画面では、自動入力された項目と手入力の項目を見分けられるように
し、すべての必須項目が「確認済み」になるまで SiteInfo を確定できないように
します。
