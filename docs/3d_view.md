# 3Dで確認する

計算した最大ボリュームを立体で確認する方法が2つあります。用途が違うので
併用するのがおすすめです。

| | ブラウザ3Dビューア | アイソメ図 |
|---|---|---|
| 出力 | 単一HTMLファイル | 図面の中の2D線分（JWW/DXF） |
| 回転・視点変更 | ◎ マウスで自由に | ✕ 固定（角度は設定で変更可） |
| 必要なもの | ブラウザだけ | JWWだけ |
| 向いている用途 | 検討・打ち合わせ・共有 | 図面化・印刷・提出 |

## ブラウザ3Dビューア

```bash
jwcad-volume 敷地.yaml --html-out volume3d.html
```

設定ファイルに `output.html3d_path` を書いておけば毎回自動で出力されます。

できたHTMLをダブルクリックすると、ブラウザで開いてマウスで回せます。

- **ドラッグ** = 回転 / **ホイール** = 拡大縮小 / **右ドラッグ** = 移動
- 左上のチェックで **最大ボリューム / 斜線制限エンベロープ / 敷地** を切り替え
- 「南西」「真上」などのボタンで定型の視点へ
- 右上のコンパスが真北の向きを示します

**斜線制限のエンベロープ（青の半透明）の中に、最終的なボリューム
（オレンジ）が収まっている**様子が見えます。エンベロープとボリュームの
すき間が、建蔽率・容積率・日影規制で削られた分です。どの規制でどれだけ
削られたかは左下のサマリーに出ます。

技術的な補足として、このHTMLは**外部ライブラリを一切使っていません**
（three.js等も、CDNへの通信もなし）。Canvas 2Dだけで描いているので、
ファイルは20KB前後、オフラインでも開け、社内ネットワークの制限や
セキュリティポリシーの影響も受けません。メール添付でそのまま渡せます。

## アイソメ図（JWW / DXF）

JWWは2D CADなので、本物の3D表示（回転）はできません。その代わり、
立体を平行投影して2Dの線分として描き込みます。**新しいソフトが一切
不要**で、そのまま図面の一部として印刷・提出できるのが利点です。

- **DXF**: `ENVELOPE-PLAN` などと並んで `ISO-SITE` / `ISO-OUTLINE` /
  `ISO-VERTICAL` の3レイヤに、平面図の上側に配置されます。
- **JWW外部変形**: 平面図の右隣に、線色を分けて作図されます。
  `gaihen_params.yaml` の `draw_isometric: false` で無効にできます。

視点は方位角と仰角で変えられます。

```yaml
isometric_azimuth_deg: 225.0    # 真北から時計回り（225=南西から見る）
isometric_elevation_deg: 30.0   # 見下ろす角度
```

方位角を変えた図を複数枚並べれば、回転できない不便はかなり補えます
（例: 225=南西 / 135=南東 / 315=北西）。

### 隠線消去について

アイソメ図は**ワイヤーフレーム**（隠れて見えないはずの線も描く）です。
隠線消去は実装していません。ボリューム検討の段階では、各段の輪郭が
すべて見えている方が「どこがどれだけセットバックしているか」を読み
取りやすいためです。

線が多すぎて読みにくい場合は、水平スライスの数（`envelope` の
`n_layers`）を減らすと段数が減って見やすくなります。なお、同じ平面
形状が続く段は自動的に1つにまとめてから作図しているので、線が無駄に
重なることはありません。

## 3Dで見えると何が変わるか

このツールの探索は「ポディウム＋タワー」という単純な形状族に限った
ヒューリスティックで、大域最適解ではありません（`methodology.md`）。
3Dで形が見えるようになると、**設計者が「ここはまだ攻められる」と判断して
手で形状を調整する**サイクルが回せます。自動探索の限界を人の目で補える、
という点が実際には大きい部分です。
