# MVE の計算方法

## 全体の流れ

    敷地図 → 壁面後退線 → 建物外郭線 → メッシュ → 各マスの階数を決める

旧版（`jwcad_volume`）は「斜線制限のエンベロープを作り、日影に引っかかったら
建物全体の高さを一律に縮小する」という方式でした。これは**設計の役に立ち
ません**。日影に効いているのは建物の一部分なのに、無関係な部分まで一律に
低くしてしまうためです。MVEはこの部分を作り直しました。

## 1. 壁面後退線・建物外郭線

各境界線から `wall_setback_m` だけ内側に入った線が壁面後退線、それで囲まれた
範囲が建物外郭線です。後退距離は次の3つに同時に効きます。

- 道路斜線・隣地斜線の**後退緩和**（建てられる高さが上がる）
- **天空率**の計画建築物の位置（測定点から遠ざかるので有利）
- 建物を置ける**範囲そのもの**

北側斜線には後退緩和がないので、後退させても北側の制限は緩みません。

## 2. メッシュ

建物外郭線を X方向・Y方向の幅で刻んだ格子を作ります。1マスが
「X × Y × 階高」のボックス1個分の底面です。幅は設定で指定でき、
`mesh_angle_deg` を与えると道路に平行な割り付けなどもできます。

マスが外郭線からはみ出す場合は、`coverage_threshold`（既定0.5）以上
入っていれば採用します。

## 3. 各マスの階数を決める

### (1) 高さ制限まで積む

各マスの4隅と中心で斜線制限を評価し、最も厳しい値をそのマスの上限とします。
階高で割った階数まで積みます。

### (2) 建蔽率で絞る

建築面積の上限を超える場合、使うマスを選び直します。このとき
**積める階数が多いマスを優先**します。同じ建築面積なら高く積める場所を
使った方が容積を稼げるためです。

### (3) 容積率で頭打ち

延床面積の上限（法52条2項の道路幅員制限を反映した値）を超えないよう、
高い柱から1階ずつ削ります。

### (4) 日影規制に合わせる ← ここが作り直しの中心

`shadow_index.py` が (測定点, 時刻, マス) ごとの**しきい値高さ**を持って
います。

    マス C が測定点 P を時刻 t に日影にする
      ⟺ C の高さ ≧ mh + r・tan(α)

（mh = 測定面高さ、r = P から太陽方向へ伸ばした半直線が C に入るまでの距離、
α = 太陽高度）

これにより、規制時間を超えた測定点について次が正確に分かります。

- どの時刻が日影になっているか
- **その時刻に日影を作っているマスはどれか**
- それらを何m下げれば日影が外れるか

時刻ごとに「解消コスト（失う体積）」を計算し、**最も安い時刻から順に解消**
します。結果として、日影に効いている北側などのマスだけが段状に低くなり、
他は上限のまま残ります。

### (5) 削った後の積み直し

日影で削ると容積率に余裕が生まれることがあります。日影に効いていないマス
（南側など）に、上限・建蔽率・容積率・日影のすべてを満たす範囲で1階ずつ
戻します。

## 効果

同じ条件（30m×20m、6m道路、第一種住居、容積率200%、建蔽率60%、
日影5時間/3時間）での比較:

| | 旧版（一律縮小） | MVE（ボクセル） |
|---|---|---|
| 延床面積 | 478 m2 | **1197 m2** |
| 最高高さ | 4.29 m | 22.40 m |
| 容積率の達成 | 約80% | **100%** |
| 日影規制 | 適合 | 適合 |

容積率の上限（1200 m2）にほぼ到達しています。旧版が容積率をまったく
使い切れていなかったのは、日影の一律縮小が過剰に効いていたためです。

テスト `test_voxel_beats_uniform_scaling_on_floor_area` が、同じ敷地で
一律縮小方式を再現して比較し、MVEの方が延床面積が大きいことを常に
確認しています。

## 限界

- **貪欲法であり、大域最適解ではありません。** 時刻ごとの解消コストが
  最小のものから順に処理する方式なので、全体を見渡した最適な配置とは
  限りません。
- **メッシュの粗さに結果が依存します。** 細かくすると容積は増えますが
  計算時間も増えます。3m角が実用的な出発点です。
- 各マスは底面から連続して積む「柱」なので、**中空やピロティ、
  オーバーハングは表現できません**。
- 平均地盤面の傾斜、令135条の12第2項の高低差緩和は未対応です
  （`legal_basis.md`）。
