# 免責事項・本ツールの位置づけ

このツール（jwcad-volume）は、建築基準法における**道路斜線制限・隣地斜線制限・
北側斜線制限**とその代替計算方法である**天空率算定**（建築基準法56条7項、
施行令135条の5～11）、および**日影規制**（建築基準法56条の2、施行令135条の12・13）
を踏まえて、敷地に建築可能な最大ボリュームを試算・作図するための**設計初期段階の
検討ツール**です。

## できること

- 敷地形状・前面道路幅員・用途地域・容積率・建蔽率などのパラメータから、
  斜線制限のみによる法的最大高さのボリューム（適合建築物相当）を算定
- 天空率算定により、斜線制限を超える高さを許容する「ポディウム+タワー」型の
  ボリューム増分を探索（一つの単純化されたヒューリスティックであり、
  理論上の最大値の保証ではありません。詳細は methodology.md を参照）
- 冬至等の指定日における日影時間を計算し、日影規制ラインでの適合性を確認
- 建蔽率・容積率の上限を反映
- JW-CAD/JWWへ読み込み可能なDXFファイルを出力

## できないこと・注意点

- **確認申請（建築確認）に使用できる精度・様式ではありません。** 実際の
  天空率算定には、告示で定められた測定点の設置方法・投影方法に厳密に
  準拠した認定ソフトウェア（メーカー製の天空率算定ソフト等）が必要です。
  本ツールの天空率計算は内部的に一貫した近似手法（等角度サンプリングによる
  正射影天空図）を用いていますが、行政・審査機関に提出する図書の作成には
  使用できません。
- 道路斜線の適用距離・勾配テーブル（別表第三）は主要なパターンを実装して
  いますが、高容積率地域の細分ケースなど、条文の全パターンを網羅しては
  いません。実際の設計では必ず最新の法令・地方公共団体の条例・要綱を
  確認してください。
- 日影規制の測定線距離・時間数（別表第四相当）はツールの入力パラメータであり、
  デフォルト値は説明用の一例に過ぎません。適用される地方公共団体の条例を
  必ず確認し、正しい値を設定してください。
- 天空率の測定点配置は敷地境界線（または前面道路の反対側境界線）上に
  簡易的な等間隔配置で生成しており、告示が定める細かな測定点設置規則
  （隅切り部分の扱い等）には完全準拠していません。
- 日影規制の測定は敷地境界からの一律オフセットラインで近似しており、
  実際の近隣地盤高低差・建物形状は考慮していません。
- 本ツールの計算結果は、必ず建築士等の専門家による確認・検証を経てから
  実務に用いてください。
