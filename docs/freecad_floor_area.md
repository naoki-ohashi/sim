# FreeCADの部屋から床面積表を作る

FreeCAD（BIM/Archワークベンチ）で作った部屋（**Space**）の床面積を集計し、
Excel（`.xlsx`）またはCSVに書き出します。

* **FreeCADの中で使う**: `freecad/床面積集計.FCMacro`（マクロ）
* **FreeCADなしで使う**: `freecad-floor-area` コマンド（保存済みの
  `.FCStd` を直接読みます）

出力はこの形です（階が2つ以上あるときだけ「階」列と小計が付きます）。

| 部屋名 | 階 | 床面積 (㎡) |
|---|---|---|
| リビング | 1階 | 16.56 |
| キッチン | 1階 | 8.28 |
| 1階 小計 | 1階 | 24.84 |
| 主寝室 | 2階 | 13.24 |
| 2階 小計 | 2階 | 13.24 |
| 合計 | | 38.08 |

## 1. FreeCADの中で使う（マクロ）

1. FreeCADで建物のファイルを開きます（BIM/Archの「スペース」で部屋を
   作っておいてください）。
2. [マクロ]-[マクロ...] から `freecad/床面積集計.FCMacro` を実行します。
3. 保存先を聞かれるので `.xlsx` か `.csv` で保存します。

マクロをFreeCADのマクロフォルダにコピーして使う場合は、マクロ冒頭の
`REPO_ROOT` にこのリポジトリの場所を書くか、環境変数 `FREECAD_AREA_ROOT`
に設定してください（`freecad_area` パッケージを読み込むためです。
`pip install` は不要で、リポジトリを置いてあるだけで動きます）。

Excel形式で出すには **openpyxl** が必要です。FreeCAD同梱のPythonに入って
いないことが多いので、その場合は `.csv` で保存してください（BOM付き
UTF-8なので、Excelでそのまま開いても文字化けしません）。

## 2. FreeCADなしで使う（コマンド）

```bash
freecad-floor-area 住宅.FCStd                 # 住宅_床面積.xlsx ができます
freecad-floor-area 住宅.FCStd -o 面積表.csv    # CSVで出す
freecad-floor-area 住宅.FCStd --all-areas     # Space以外の面積も集計する
```

`.FCStd` はZIPで、中の `Document.xml` に各オブジェクトのプロパティ値が
保存されています。床面積もその中にあるので、FreeCADを起動しなくても
読めます（インストール不要・追加の依存パッケージもCSV出力だけなら
ありません）。

## 面積の取り方（ここが要点）

**`Shape.Area` を床面積に使ってはいけません。** `Shape.Area` は立体の
**全表面積**（床＋天井＋壁）です。4m×3m×高さ2.4mの部屋なら、床面積
12㎡に対して `Shape.Area` は 12＋12＋33.6＝57.6㎡ になり、5倍近い値に
なります。

このツールは次の順で床面積を決めます。

1. **`Area` プロパティ**（`App::PropertyArea`）。Arch Space が持っている
   水平投影の床面積です。通常はこれが使われます。
2. `Area` が無い場合のみ、**形状の最下部にある水平面の面積の合計**を
   使います（底面が水平な立体を想定。L字型など底面が複数の面に分かれて
   いても合算します）。斜めの床など、水平な最下面が取れない場合は空欄に
   なり、合計にも含めません（実行時に部屋名を知らせます）。

部屋かどうかの判定も、FreeCADのバージョン差を吸収するため次のいずれかで
行います（`obj.TypeId` に "Space" を含むかどうかだけを見る判定では、
Arch Space の `TypeId` が `Part::FeaturePython` なので**1件も拾えません**）。

* `IfcType` / `IfcRole` が `Space`
* Pythonプロキシのクラスが `_Space`（`obj.Proxy.Type == "Space"`）
* `TypeId` に `Space` を含む
* 内部名が `Space` / `Space001` … で、かつ面積プロパティを持つ

「階」列には、その部屋を含むグループ（通常は階を表す BuildingPart）の
ラベルが入ります。建物（Building）が部屋を直接持っている場合は建物名に
なります。

## 制限と注意

* **法令上の床面積とは別物です。** ここで出るのは3Dモデルの `Space` の
  面積であり、壁芯・壁内法のどちらで部屋を作ったか、小屋裏収納・
  ロフト・吹抜け・玄関ポーチ等をどう扱うかはモデルの作り方次第です。
  建築基準法上の床面積・延べ面積として使う前に、必ず内容を確認して
  ください（`docs/disclaimer.md`）。
* FreeCADなしで読む機能は、保存時点で記録されている値だけを読みます。
  `Area` プロパティを持たないオブジェクトの床面積は求められません
  （形状データ(BREP)は解析しません）。その場合はFreeCADの中でマクロを
  実行してください。
* `Document.xml` の書式はFreeCADのバージョンに依存します。テストは
  FreeCADが書く構造を模したファイルで行っており、**FreeCAD実機での
  検証はしていません**。手元のファイルで一度結果を確認してから常用して
  ください。うまく読めない場合は、FreeCADの中でマクロを実行する方
  （こちらは実際のAPIから値を取ります）を使ってください。
* 列挙型プロパティ（`IfcType` など）は `.FCStd` には添字の整数でしか
  保存されないため、FreeCADなしで読むときは判定に使えません。上の
  プロキシのクラス名・内部名で判定しています。

## テスト

```bash
pytest tests/freecad_area
```

FreeCAD本体はCIに入れられないので、FreeCADのオブジェクトを模したダミー
（`tests/freecad_area/fakes.py`）と、`Document.xml` と同じ構造を組み立てる
ヘルパー（`tests/freecad_area/fcstd_fixture.py`）でテストしています。
